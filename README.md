# SHAHI AGRO FARM

Run locally: `npm install` then `npm run dev`.

## Publish live (GitHub Pages)
1. Push this project to the `main` branch of your repo (shahiagrofarm/SHAHI-AGRO-FARM-WEB).
2. In GitHub: Settings → Pages → Source: **GitHub Actions**.
3. Every push to `main` builds and deploys automatically.
Live URL: https://shahiagrofarm.github.io/SHAHI-AGRO-FARM-WEB/
